# Расширенные и опубликованные комплекты

Обычная сборка текущих исходников — [make build](build.md), scan —
[руководство пользователя](../user/README.md). Здесь сохранены низкоуровневые
операции сопровождающего и совместимый путь **опубликованного v0.2.0**,
который ещё не содержит нового Make/CLI интерфейса.

| Задача | Инструкция |
| --- | --- |
| Получить v0.2.0: публичные GHCR и архивы AMD64/ARM64 | [Релиз v0.2.0](releases-v0.2.0.md) |
| Установить готовый offline-пакет | [Import → verify → контрольный snapshot](installation.md) |
| Просканировать с явным deployment | [Explicit launcher](explicit-launcher.md) |
| Вручную подготовить новый кандидат, locks и export | [Расширенная CPU-сборка](advanced-build.md) |
| Использовать прежний Jenkins adapter | [Explicit Jenkins](jenkins-explicit.md) |
| Прочитать инструкцию первого ARM64-релиза | [Архив v0.1.0](releases-v0.1.0.md) |
| Разобраться в locks/engine/provenance | [Артефакты](../reference/artifacts.md) |

Архивный маршрут не отменяет проверки IDs, платформы, приватности и baseline.
Pull образа сам по себе не устанавливает launcher/engine. Существующие релизы,
теги, manifests и hashes неизменны; документация текущей ветки не означает
нового опубликованного выпуска. [Исторические протоколы](../../verification/README.md).
