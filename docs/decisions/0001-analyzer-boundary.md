# ADR-0001: отдельный механизм распознавания

Статус: принято 2026-10-18 в общем плане; реализация — этап 2.

## Контекст

Прокси уже содержит правила, NER, обработку длинного текста и оценку качества.
Scanner должен получать дальнейшие улучшения без переписывания Git и отчётов.

## Решение

Отдельные контейнеры scanner/analyzer, локальный HTTP API, закреплённые
исходники и образ прокси. Источник находки выдаётся минимальным адаптационным
патчем. Словарь вне Analyzer переносится отдельно с той же семантикой.
Подготовка исходников и загрузка модели происходят до автономного запуска.

## Последствия

Смена модели/правил — обновление lock/образа с проверками, API-изменение —
адаптация клиента. Есть стоимость запуска второго контейнера и контроля
совместимости патча. Плавающие версии и разрозненное копирование детекторов
в scanner не используются. Общая библиотека может стать будущим решением,
но требует отдельной согласованной работы над upstream.
