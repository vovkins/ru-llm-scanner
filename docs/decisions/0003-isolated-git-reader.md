# ADR-0003: изолированный metadata-view для чтения Git

Статус: принято и реализовано на этапе 3 по [согласованному плану #5](https://github.com/vovkins/ru-llm-scanner/issues/5), 2026-10-19.

## Контекст

Произвольный клон содержит недоверенные config, hooks, attributes, refs и
ссылки хранилища. Только `git -c core.hooksPath=...` поверх исходного git-dir
не исключает config includes, внешние пути и promisor remotes. Checkout и
чтение рабочих файлов не соответствуют аудиту состояния коммита.

## Решение

Создаём приватный временный bare metadata-view с минимальной собственной
конфигурацией. Из оригинала после проверки копируются только HEAD/refs,
packed-refs и shallow; исходный config разбирается без includes только для
проверки формата. Object store подключается отдельно после проверки layout
и отсутствия symlinks/alternates. Унаследованное Git-окружение не используется.

`rev-parse` фиксирует commit, `cat-file --batch` читает типизированные объекты
с дедлайном. Сырые деревья разбираются собственным ограниченным парсером;
пути не используются как host-пути. Полные объекты сверяются по Git OID.
Reader не запускает diff, фильтры, hooks, код проекта или сетевые helpers.

Выбор A/B, классификация/кодировки и будущие детекторы разделены. `selected`
и `ready` не означают успешное сканирование; такое решение принимается позже
в pipeline после ответа Analyzer и словаря. В diff неизменённые blobs не читаются.

## Последствия и границы

Самодостаточные обычные и bare-клоны, SHA-1/SHA-256, packfiles и доступные
shallow/partial объекты работают без полной истории. Внешние git-dir, commondir,
alternates, symlinks в metadata/object store и неизвестные storage extensions
дают явную ошибку. Предварительная подготовка отдельного клона — действие
оператора вне reader. Hidden fetch не исправляет неполный вход.

Объекты должны оставаться неизменными на протяжении контекста; активная
параллельная замена хостовым процессом за пределами модели доверия.
Временный view фиксирует refs и не изменяет исходные metadata/рабочую папку.
Лимиты/ошибки и воспроизводимые тесты описаны в [Git reader](../git-reader.md).
