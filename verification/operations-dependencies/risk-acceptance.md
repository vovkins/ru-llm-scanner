# Решение владельца по остаточным native-рискам

Дата: **2026-10-20 (MSK)**. Основание — явное решение владельца проекта в чате:

> Я принимаю решение игнорировать эти уязвимости. Для экспулатации внутри нашего закрытого контура эти уязвимости неактуальны.

Статус: **принято владельцем для эксплуатации в закрытом контуре**.
Решение относится к четырём остаточным advisory, разобранным перед этим
сообщением, в текущем кандидате ru-llm-scanner PR #29:

| Advisory | Source/version кандидата | Решение |
| --- | --- | --- |
| CVE-2026-102010 | gcc-14 14.2.0-19 | Риск принят владельцем для закрытого контура |
| CVE-2026-19542 | glibc 2.41-12+deb13u4 | Риск принят владельцем для закрытого контура |
| CVE-2026-27171 | zlib 1:1.3.dfsg+really1.3.1-1 | Риск принят владельцем для закрытого контура |
| CVE-2026-85091 | zlib 1:1.3.dfsg+really1.3.1-1 | Риск принят владельцем для закрытого контура |

Комплект: [IDs images и платформа Linux ARM64](final-images.json),
[runtime lock](candidate.runtime.lock.json), [deployment](candidate.deployment.json).
Техническое основание: [подробный разбор](native-risk-detail.md),
[измеренные native evidence](native-reachability.json),
[текущие dispositions](native-dispositions.json).

Решение завершает требуемый от владельца выбор по DEP-01 для этого комплекта
и контура. Пакеты и images при его фиксации не менялись;
`fixed_in_candidate` для этих записей остаётся `false`. Исходные advisory,
пределы проверки достижимости и результаты аудита сохранены. CVE-2026-95619
имеет отдельное обоснование неприменимости к исследованной системной ARM64
сборке; принятие риска к ней не требуется.

Это решение не отключает последующие аудиты и не распространяется автоматически
на новые уязвимости, другие комплекты или окружения. Следующий шаг — отдельное
согласование плана итоговой приёмки #25. Её выполнение, слияние PR, смена
штатного deployment, релиз и публикация образов этим сообщением не согласованы.
