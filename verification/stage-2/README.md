# Проверка этапа 2

Проверки выполнены 18–19 октября 2026 года по плану [#3](https://github.com/vovkins/ru-llm-scanner/issues/3).
Результат относится к механизму анализа, а не к ещё не реализованному сканированию
Git, HTML/JSON renderer, baseline или пользовательскому Docker/Jenkins запуску.

## Артефакты и среда

- [Source lock](../../upstream.lock.json): upstream
  `da4f50a87ddf8a6c160c5f1893f5bf526f713d1c`, 97 файлов,
  отдельный патч API и контрольные суммы модели/словаря.
- [Измеренный runtime lock](../../locks/analyzer-cpu-linux-arm64.runtime.lock.json):
  CPU `linux/arm64`, фактические платформенный Image ID и локальная ссылка
  запуска, source/build provenance, 71 пакет, spaCy tree и модельные хеши.
- [Реальная модель и соответствие upstream](offline-verification.json).
- [Тесты upstream](upstream-tests.json).
- [Метаданные лицензий и хеши notices установленных пакетов](licenses.json).

Стенд: macOS/Apple Silicon, Docker 29.6.1, Linux ARM64; инструменты разработки
Python 3.12.14, runtime Python 3.11.16. NER:
`fef2/ner_rus_bert-secret_detection@52b5b0745aac14f73fcf2ac0f91d9b5001a85ae4`.
GPU inference не проверен: CUDA недоступна. CPU AMD64 и GPU требуют собственных
build profiles, pins, сборки и аппаратных проверок. Работающие проекты для
освобождения ресурсов не останавливались. Tracked-состояние соседнего прокси
не изменено; его локальные config/secrets/tmp не читались и не экспортировались.

## Результаты

| Проверка | Результат |
| --- | --- |
| Unit-тесты scanner | 31 passed, без skipped |
| Семь наборов upstream-тестов | 478 passed |
| Исходный сервер и патченный API через адаптер | Совпали 77/77 текстов: категории, значения, интервалы, score с абсолютным допуском `1e-7` |
| Источники обнаружения | На корпусе наблюдались все четыре источника Analyzer и восемь rule IDs |
| Словарь | 4 интеграционных случая и 5 unit-тестов, исходные координаты/повторы/границы/перекрытия |
| Реальная NER | Короткий/длинный текст, хвост последнего окна и Unicode прошли |
| Сбои | Отклонены API без патча, смена профиля, остановка сервиса, отсутствующая модель, неверный хеш; нет успешного regex-only fallback |
| GPU на CPU-стенде | Явный отказ запроса GPU; переход на CPU не выполняется |
| Сеть | Модельная проверка и upstream-тесты выполнены с `--network none`, файловые mounts read-only |
| Подготовка | Локальный клон и явный fetch полного закреплённого SHA дают одинаковые manifest и файлы |

Model report содержит хеши проверенного кода scanner и integration harness;
исходники не менялись во время сравнения. Все quality gates исходного корпуса
прошли, численные результаты находятся в JSON. Это небольшой синтетический
корпус upstream, не промышленная оценка полноты на произвольном коде.
Отдельный корпус исходников/конфигураций запланирован на этапе 4.

JSON здесь — служебные артефакты проверки, не отчёты будущего scanner по
`report-v1.schema.json`. Они содержат метрики и идентификаторы, без исходных
текстов и найденных значений. Полные локальные логи не публикуются.
Runtime lock описывает конкретный локально собранный образ; его наличие
не означает публикацию образа в registry или релиз проекта.

## Повторение

Команды подготовки, сборки, seal, unit/upstream/offline-проверок и инвентаризации:
[руководство Analyzer](../../docs/analyzer.md),

просто приписать новому образу. Проверка формы lock не удостоверяет подлинность
чужого JSON. Собственная лицензия scanner пока не выбрана;
[статус уведомлений](../../docs/licensing.md) сохраняется явно.
