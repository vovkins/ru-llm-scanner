# Проверка этапа 3

План [#5](https://github.com/vovkins/ru-llm-scanner/issues/5) согласован
2026-10-19. Проверен внутренний Git/text API; поиск детекторами, отчёты,
baseline, scan CLI и пользовательский Docker/Jenkins запуск сюда не входят.

## Результаты

| Набор | Результат | Среда |
| --- | --- | --- |
| [Git/text на хосте](host-tests.json) | 41 passed, без skipped | macOS ARM64, Python 3.12.14, Apple Git 2.39.5 |
| [Git/text в контейнере](linux-tests.json) | 41 passed, без skipped | Linux ARM64, Python 3.11.16, Git 2.47.3; UID 65534, `--network none` |
| Полный unittest проекта | 72 passed, без skipped | Host venv, включая прежние проверки адаптера/артефактов/словаря |

JSON фиксирует хеши проверенных модулей, fixtures, тестов и harness; они не
менялись во время прогона. Linux launcher сохраняет фактические reference и
платформенный Image ID dev-образа, проверяет только loopback среди активных
интерфейсов. В container передаются только перечисленные исходники read-only,
без `.git`, model assets или локальных конфигов. Временные тестовые репозитории
создаются в tmpfs; capabilities отсутствуют, привилегии не повышаются.

В наборах проверены:

- Самодостаточные клоны и bare, SHA-1/SHA-256, packfiles, shallow с отсутствующим
  родителем, доступный снимок и недостающие commit/tree/blob. Promisor-pack с
  недостающим blob даёт ошибку без запуска fetch/helper.
- Snapshot и сравнение ровно A/B: изменения mode/type, added/deleted/exact rename,
  неоднозначные rename-пары, merge, независимые состояния, A=B, пустое дерево.
  Значение из промежуточной истории не выдаётся за содержимое B.
- Сырые пути с пробелами/tab/LF/ESC, не-UTF-8 и одинаковым отображением разных
  байтов, начальным дефисом и Unicode; битые/опасные/дублирующиеся tree entries.
- Игнорирование рабочей/staged/untracked версии, неизменность metadata/index/
  refs/файлов и чтение с read-only правами. Удалённые и неизменённые blobs
  не открываются; rename проверяется по новому пути.
- Недоверенные config/includes/hooks/filters/textconv/helpers, унаследованные
  Git/loader-переменные, replace refs/grafts; marker-команды не выполняются.
  Внешние git-dir/commondir/alternates/symlinks и FIFO отклоняются.
- Хеши полных объектов, повреждённое содержимое, ошибки ОС, дедлайны непрерывного
  медленного потока, остановка children, лимиты дерева/вывода/выбранного текста.
- Полная таблица сигнатур `text-v1` и ложные/усечённые сигнатуры, обычный текст
  с бинарным расширением, LFS с extensions и near-matches, scope и пустые файлы.
- UTF-8/BOM UTF-16/32/cp1251, explicit endian, конфликты codecs/BOM, NUL, неверные
  байты/surrogates, CR/LF/CRLF, emoji/combining marks и сохранение полного текста.

Это 41 test method с параметризованными подслучаями, а не 41 файл или категория
данных. В JSON нет текстов файлов и найденных значений; это dev evidence,
не `report-v1.schema.json` и не результат сканирования чувствительных данных.
Полные логи синтетических assert остаются локально.

## Ограничения и повторение

Команды и границы layout/операционных лимитов — в [Git reader](../../docs/git-reader.md),
полный прогон — в [development](../../docs/development.md).
Объекты входа должны оставаться неизменными; защита от активной хостовой
подмены во время чтения не заявлена. Linked/shared/reftable layouts дают
явную ошибку. Windows-native и другие CPU-архитектуры не проверены.

Исходники Analyzer/модель/словарь/locks на этапе 3 не менялись. Повторный
модельный inference без изменения механизма не выполнялся; его отдельные
результаты остаются в [этапе 2](../stage-2/README.md). Соседний proxy не менялся,
работающие проекты не останавливались. Dev-образ локальный, не опубликован.
