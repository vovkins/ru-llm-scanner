План [#7](https://github.com/vovkins/ru-llm-scanner/issues/7) согласован 2026-10-19.
Реализованы внутренний snapshot/diff pipeline, эффективная конфигурация,
profile/manifest hashes, находки/координаты/контекст, охват и безопасные ошибки.
Пользовательский CLI, JSON/HTML writer и baseline — следующий этап.

Unit-тесты проверяют strict config/профиль, сырые пути и стабильные ID,
Unicode/CRLF/EOF/многострочный контекст, повторения, snapshot/diff/A=B,
unsupported/excluded/ошибки/неизменность входа, таймауты/503/невалидный ответ,
смену подписи, ограничение очереди/HTTP, отмену/повторную отмену, закрытие потоков,
ошибку словаря и финальную проверку готовности. Для `c=2` проверено максимум
5 прочитанных текстов при остановленных workers и максимум 2 HTTP-анализов.

Реальная проверка использует оба закреплённых слоя и сверяет все категории,
смещения, source/rule и score с прямым вызовом (допуск score `1e-7`). Значения
и координаты проверяются по исходным строкам независимо. Дополнительно
проверены значение вне изменённой строки, длинный хвост, многострочный ключ,
diff/A=B без baseline, сохранение завершённых находок при decode error и отказ
при неправильной подписи. Корпус охватывает все 30 категорий Analyzer и словарь.

Модель: `fef2/ner_rus_bert-secret_detection`, ревизия
`52b5b0745aac14f73fcf2ac0f91d9b5001a85ae4`; upstream
`da4f50a87ddf8a6c160c5f1893f5bf526f713d1c`. Полные хеши кода, корпуса,
артефактов, профиля и реальные platform/reference Image ID сохранены в JSON.
Измерение `scan_elapsed_seconds` — около 8.2 секунды от создания синтетического
Git-репозитория до завершения snapshot 46 файлов, включая ожидание readiness.
Это небольшой корпус, не SLA по времени/памяти и не нагрузочная характеристика
10 MiB файлов.

## Независимое качество code-v1

Это отдельная оценка качества существующего механизма, а не условие
тождественности API. 46 случаев включают 37 ожидаемых мест и 12 отрицательных
примеров. Exact match требует совпадения категории и обеих границ.

| Метрика | Значение |
| --- | --- |
| Exact TP / FP / FN | 33 / 13 / 4 |
| Exact precision | 71.74% |
| Exact recall | 89.19% |
| Значения, покрытые сущностью той же категории | 33 из 37 |

Четыре несовпавших ожидания:

| Случай | Ожидание | Фактическое поведение |
| --- | --- | --- |
| `http-bearer` | BEARER_TOKEN | AUTH_TOKEN с другими границами |
| `encoded-data` | BASE64_DATA | Разделённые SECRET_KEY и PASSWORD |
| `contact-phone` | PHONE_NUMBER в CSV | Находки нет |
| `inn-yaml` | RU_INN | PHONE_NUMBER на том же интервале |

Extras включают дополнительные ORGANIZATION, в том числе рядом с корректными
DICTIONARY_TERM, и срабатывания на отрицательных примерах: неверный ИНН как
телефон, URL как LOGIN/PERSON, короткая base64-подобная строка как PASSWORD.
Дополнительная категория считается FP относительно ограниченной разметки;
это не всегда означает, что в исходном тексте совсем нет сущности этой категории.
Все missing/extra с категориями и offsets сохранены в JSON по каждому case.

Разметка/threshold/model/rules/allowlist после измерения не менялись. Источник
ошибок воспроизводится прямым вызовом; pipeline не теряет эти ответы.
Корпус мал и синтетический, не представляет все языки/стили кода, не доказывает
действительность credentials и не позволяет обещать абсолютную полноту.
Повышение качества требует отдельно согласованной работы с механизмом и новым
профилем; текущие ограничения сохраняются при создании отчётов/baseline.

## Изоляция и повторение

[Команды](../../docs/scan-api.md) создают временный Analyzer с `--network none`;
scanner использует его loopback namespace, UID 65534, read-only FS/исходники,
без capabilities и повышения привилегий. Подтверждено отсутствие внешнего
маршрута. Передаются только явные синтетические fixtures и доверенные assets,
без рабочего репозитория/.git/secrets. Исходники хешируются до/после.
Собственные контейнеры удалены после прогона; работающие проекты не остановлены.

JSON здесь — служебное evidence без values/context, не scan_report v1 и не
baseline. Локальные assert-логи могут содержать синтетические данные; они не
публикуются. Соседний proxy, модель, словарь, source/runtime locks не изменялись.
CPU ARM64 проверен; GPU, Windows-native и другие CPU не заявлены проверенными.
Dev-образ локальный, релиз не опубликован, лицензия scanner не выбрана.
